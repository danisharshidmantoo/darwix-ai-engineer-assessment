# Objections & Example Responses

## 1. "Cicilan kemahalan" / "angsurannya besar"
- Respon: Jelaskan breakdown suku bunga dan tenor; tunjukkan opsi tenor lebih panjang atau promosi DP lebih rendah untuk menurunkan angsuran.

## 2. "Saya mau nego DP" / "Bisa kurang DP-nya?"
- Respon: DP adalah hasil penilaian risiko; bila nasabah meminta, sampaikan opsi program promo dengan DP 0% atau rujuk underwriting untuk review manual.

## 3. "Kalau telat bayar gimana?"
- Respon: Jelaskan grace period, denda (denda keterlambatan), dan opsi restrukturisasi jika memenuhi syarat.

## 4. Colloquial mix: "Medyo mepet, bisa dicicil maticnya?"
- Respon: Tanyakan tenor dan tawarkan simulasi angsuran (estimasi cicilan). Gunakan bahasa yang ramah: "Tenang, kita cek opsi tenor biar lebih ringan."
