# AI Engineer Intern — Job Description

## Role summary

The AI Engineer Intern will support a small applied-AI team building
voice and retrieval-based assistants. The intern will work on real
components under supervision, including data preparation, retrieval
pipelines, and evaluation scripts.

## Responsibilities

- Assist in building and testing retrieval-augmented generation (RAG)
  components, including document ingestion and chunking.
- Write and maintain unit tests for data pipeline components.
- Help evaluate model outputs against labeled examples.
- Document experiments and pipeline decisions clearly enough for other
  engineers to continue the work.
- Participate in code review and incorporate feedback promptly.

## Required qualifications

- Currently pursuing or recently completed a degree in Computer Science,
  Data Science, or a related field.
- Working proficiency in Python.
- Basic understanding of how large language models and embeddings work.
- Comfortable with git-based workflows.

## Preferred qualifications

- Prior exposure to a vector database (any of Chroma, FAISS, Pinecone,
  Weaviate).
- Experience writing automated tests (pytest or similar).
- Familiarity with speech-to-text or text-to-speech APIs.

## Internship details

- Duration: 12 weeks (synthetic figure for this assessment).
- Format: Remote, with weekly syncs.
- Mentorship: Paired with a senior engineer for the duration of the
  internship.

## What this role is not

- This is not a purely research role; deliverables are expected to be
  working, tested code.
- This is not a full-time offer; conversion to full-time is a separate,
  later process and is not guaranteed.
